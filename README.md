# Mini Project Vite + React + TailwindCSS

This is a small React project built with **Vite** and **TailwindCSS** for a simple React project.  
It implements several component:

- **1:** Component Creation and State Management
- **2:** Form Handling and Validation
- **3:** API Integration
- **4:** Multi-page routing (Home & About)

---

Clone the repository and install dependencies:

```bash
git clone https://github.com/NayNadyaa/vite-project.git
cd vite-project
npm install
npm run dev

Notes:
Make sure to use Node.js v18+ and npm v9+.
This project was developed and tested on Node v20.19.5.
